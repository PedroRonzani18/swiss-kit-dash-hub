# Swiss Kit Core v0.1.0

## Status

Prepared for release; not tagged, published, or deployed.

## Release contents

`v0.1.0` packages the current Swiss Kit Core baseline:

- Google OAuth authentication, HttpOnly JWT cookie session, and session
  invalidation after user deactivation;
- users, seed administrator provisioning, and local access control;
- protected web shell, health/readiness endpoints, and Swagger API docs;
- shared Zod contracts; and
- a static settings overview plus the static `tasks` reference module.

The authoritative scope classification remains the [capability matrix](../current/capability-matrix.md).

## Deliberate exclusions

- Settings persistence and editing are not included.
- `tasks` is reference-only and has no workflow.
- Files and notifications are not implemented optional capabilities.
- Multi-tenancy is out of scope and not implemented.

## Compatibility

This release starts the `0.1.x` line. During `0.x`, a breaking change to the
supported public surface requires a minor-version increment; patch releases
are backward-compatible fixes only. See the root [changelog](../../CHANGELOG.md)
for the complete policy.

## Update model for derived projects

Upstream changes are adopted by manual review and selective merge. Derived
projects must assess contract, Prisma, environment, authentication,
authorization, and deployment differences, then run their own validation and
manual OAuth test. Automated upstream synchronization is not provided.

This prepared baseline includes a `User.sessionVersion` Prisma migration. Apply
migrations before starting a derived project that adopts `v0.1.0`.

## Remaining release gates

Repository validation and a disposable derived-project instantiation have
passed. Deployed-domain OAuth testing and post-deploy health/API-doc checks
remain pending. Details and required evidence are in
[release readiness](../current/release-readiness.md).
